# KUET Tech Club
## Overview

The KUET Tech Club Management System is a dynamic web-based club management platform developed using PHP, MySQL, HTML, CSS, and JavaScript. The system allows students to apply for club membership, enables administrators to manage applications, and displays approved members on the website.

The project demonstrates both frontend and backend web development concepts including form handling, database operations, session management, cookies, file uploads, and administrative control panels.

## User Features
- Responsive multi-page website
- Home, About, Events, Gallery, Members, and Join pages
- Dark/Light theme toggle using JavaScript and Local Storage
- Membership registration form
- Image upload during registration
- Member dashboard after successful registration
- Session and cookie management
- Approved members displayed dynamically from database
- Back-to-top button
- Font Awesome icons integration

## Admin Features
- Secure admin login system
- View pending membership applications
- Approve member requests
- Edit member information
- Delete member records
- Logout functionality
- Dynamic dashboard connected with MySQL database

## Basic Working Procedure

Users submit membership applications through the registration form. The submitted information is stored in the MySQL database with a pending status. Administrators can log in to the admin dashboard to review applications and approve, edit, or remove them. Once approved, members are automatically displayed on the Members page along with their uploaded profile images.
